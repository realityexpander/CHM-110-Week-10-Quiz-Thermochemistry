Scoring: A first-try correct answer is counted under Correct; a question solved after an error or hint is counted under Correct after attempts. Incorrect counts questions with one or more wrong attempts (only once per question). Skipped includes unanswered questions and answer reveals. Percent correct = (Correct + Correct after attempts) / (Correct + Correct after attempts + Skipped). Streak counts consecutive first-try completions. Scores reset for v4 because the scoring categories changed.

Scientific notation: You may type 1.10x10^23, 1.10*10^23, 1.10×10^23, or 1.10e23. Displayed answers use the form 1.10 × 1023, not e-notation.

Significant figures and tolerance: Numerical entries within ±1.5% of the calculated answer are accepted when the required significant-figure count also matches. Enter explicit trailing zeros, e.g. 2.30, not 2.3; use scientific notation to disambiguate large integers. Exact conversion factors do not limit precision.

Atomic masses: H = 1.01, C = 12.01, N = 14.01, O = 16.00 g/mol (course conventions); S = 32.06, F = 19.00 g/mol for the added gas compounds. Gas-mass question prompts show chemical names only, so derive the formula yourself.

Units Mode: OFF displays the target unit beside the typed number. ON hides it and asks you to choose the correct unit from at least four options after the number is correct. Numbers are always entered in the units requested by the question (not converted to alternate units). In conceptual questions, type the classification instead.

STP: This course uses 0°C, 1 atm, and 22.4 L/mol. Ideal gas calculations use R = 0.08206 L·atm/(mol·K). The application uses MathJax from a CDN to render LaTeX, so an internet connection is recommended on first load.
